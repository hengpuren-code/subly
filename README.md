# Subly

> **See every subscription. Stop paying for what you forgot.**
> 看清每一笔订阅，别再为忘掉的东西付钱。

一个人做的、本地优先的订阅支出追踪器。数据只存在你自己的浏览器里。

---

## 1. 立项：为什么做这个

**痛点**
订阅经济下，一个普通人手里攥着十几个自动续费：视频会员、云盘、软件、健身房、外卖会员。
它们金额小、频率高、自动扣款，以至于没人真的在手边看着这笔钱。
结果是：每年有相当一部分钱，花在了自己早就忘了的服务上。

**现有产品为什么没解决**
- 银行 App：只显示扣款，不知道"这是什么"，也无法提前预警
- 记账 App：太重，要手动记每一笔，坚持不下来
- 海外订阅管理器：要连银行账户、要注册账号、要上传隐私数据

**我的切口**
一个**不需要注册、不需要联网、不碰你隐私**的小工具：
你把订阅手动录进去（第一次花 2 分钟），之后它帮你算清月度/年度支出、盯住续费日。
数据 100% 留在本地。

## 2. 目标用户

- 有 5 个以上订阅、开始觉得"钱不知道花哪了"的个人
- 想省钱但不想被记账 App 绑架的人
- 隐私敏感、不想把银行流水交给第三方的人

## 3. 产品规格（MVP）

| 功能 | 说明 |
|---|---|
| 添加订阅 | 名称、金额、周期（周/月/季/年）、下次续费日、分类 |
| 列表与排序 | 按下次续费日 / 金额排序 |
| 统计 | 折算月均支出、年均支出、即将续费项 |
| 续费提醒 | 可调提前天数（3/7/14/30 天）的到期面板 + 逾期高亮 + 浏览器本地通知（可选） |
| 编辑 / 删除 | 完整增删改 |
| 本地持久化 | localStorage，刷新不丢，离线可用 |
| 导入 / 导出 | JSON 备份与迁移 |
| 免费额度 | 免费版最多 8 个订阅 |

**非目标（MVP 不做）**：多用户、云同步、银行对接、手机 App、账号体系。

## 4. 技术选型

- **纯静态**：HTML + CSS + 原生 JS，零依赖、零构建
- **无后端**：数据存 `localStorage`；导出走文件下载
- **部署**：任意静态托管（Cloudflare Pages / GitHub Pages / Netlify）

选这套的唯一原因：**一个人维护得动**。没有服务器就没有运维，没有依赖就没有升级地狱。

## 6. 本地运行

```bash
cd subly/site
python -m http.server 8080
# 打开 http://localhost:8080
```

> 应用用了 ES Module，必须通过 http 访问，直接双击 `app.html`（file://）会被浏览器拦。

## 6.1 本地测试

```bash
cd subly
node --test test/smoke.mjs
```

## 6.2 使用说明

1. 打开 `app.html`（本地运行时是 `http://localhost:8080/app.html`）
2. 点右上角「添加订阅」，填写名称、金额、计费周期、下次续费日、分类，保存
3. 顶部三张卡片实时显示：**每月等价支出 / 每年等价支出 / 未来 7 天内到期数量**
4. 用「排序」在「按续费日」和「按金额」之间切换
5. 每行可「编辑」或「删除」；7 天内到期的续费日会高亮为橙色
6. 「导出备份」下载 JSON；「导入」从 JSON 恢复或迁移
7. 免费版最多 8 个订阅，触顶会提示升级 Pro

## 7. 变现（Pro 版设想）

免费：≤ 8 个订阅，基础统计。
Pro（一次性买断或低价年费）：无限订阅、续费提醒、多币种、CSV 导出、深色主题包。
